# Data-Structures-and-Algorithms
A Car Rental Management System built in Python using Data Structures and Algorithms.

# 1. Introduction

The Car Rental Management System is a Python-based application designed to manage the rental operations of a car rental service. The system allows users to add, update, delete, search, display, sort, rent, and return cars.

The project demonstrates the practical implementation of Data Structures and Algorithms, along with file handling and exception handling. A Linked List is used to store car information, a Queue is used to manage rental requests, and a Stack is used to maintain rental history.

The system also stores data in text files so that information can be preserved even after the program is closed.

# 2. Problem Statement

Managing car rental information manually can be time-consuming and may lead to difficulties in maintaining car availability, rental records, and customer information.

The proposed system provides a simple computerized solution for managing cars and rental transactions efficiently using Python and fundamental data structures.

# 3. Objectives

The main objectives of the project are:

To develop a simple car rental management system using Python. ,
To implement Linked List, Queue, and Stack data structures. ,
To provide functionality for adding, updating, and deleting cars. ,
To search cars using Car ID, brand, or model. ,
To sort cars according to price, brand, and model. ,
To manage car rental and return operations. ,
To maintain rental history. ,
To calculate rental bills and total revenue. ,
To store and retrieve data using text files. ,
To handle invalid inputs and file-related errors using exception handling. 

# 4. Scope of the Project

1. Display all cars
2. Search for a car
3. Add a new car
4. Update car information
5. Delete a car
6. Sort cars by price
7. Sort cars by brand
8. Sort cars by model
9. Rent a car
10. Return a car
11. Display rental history
12. Display rental summary
13. Save and load data using text files

# 5. Algorithms and Operations

Linear Search — used to find a car by ID, brand, or model.

Sorting — cars can be sorted by price, brand, or model.

Linked List Traversal — used to access stored car records.

Queue Operations — used for rental request processing.

Stack Operations — used for storing rental history.

Error Handling: Python Exception Handling

# 7. Expected Outcome

The expected outcome is a functional console-based Car Rental Management System that can efficiently manage car records and rental transactions.

The project demonstrates how fundamental data structures can be applied to a real-world management problem while also providing persistent data storage and error handling.
